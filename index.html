Daevalog packages

Package repositories for Daevalog DPS Meter, a damage meter for AION 2 on Linux.

Once the repository is added, the meter updates with the rest of the system. The repositories keep the newest three builds.

Every package and repository index here is signed with this key:

Seralth <packages@seralth.com>

Fingerprint: 33F1 E9F7 59E2 887D 2637 2C35 5024 29F6 C085 461C

Public key: daevalog.asc

  • Arch Linux and Arch-based
  • Debian 13, LMDE 7, Linux Mint 22, Pop!_OS 24.04
  • Fedora
  • Bazzite and other image-based Fedoras
  • openSUSE Tumbleweed

Arch Linux and Arch-based (CachyOS, EndeavourOS, Manjaro)

Add the key and trust it:

curl -fsSLO https://packages.seralth.com/daevalog.asc
sudo pacman-key --add daevalog.asc
sudo pacman-key --lsign-key 33F1E9F759E2887D26372C35502429F6C085461C

Add these lines to the end of /etc/pacman.conf:

[daevalog]
Server = https://packages.seralth.com/arch/$arch

Install:

sudo pacman -Syu daevalog-dps-meter

Debian 13, LMDE 7, Linux Mint 22, Pop!_OS 24.04 (.deb)

sudo curl -fsSLo /etc/apt/keyrings/daevalog.asc https://packages.seralth.com/daevalog.asc
sudo curl -fsSLo /etc/apt/sources.list.d/daevalog.sources https://packages.seralth.com/daevalog.sources
sudo apt update
sudo apt install daevalog-dps-meter

Install curl first if it is missing (sudo apt install curl).

Fedora

sudo dnf config-manager addrepo --from-repofile=https://packages.seralth.com/daevalog.repo
sudo dnf install daevalog-dps-meter

dnf asks once to import the key. Check that the fingerprint matches the one above.

Bazzite and other image-based Fedoras

sudo curl -fsSLo /etc/yum.repos.d/daevalog.repo https://packages.seralth.com/daevalog.repo
rpm-ostree install daevalog-dps-meter
systemctl reboot

openSUSE Tumbleweed

sudo rpm --import https://packages.seralth.com/daevalog.asc
sudo zypper addrepo https://packages.seralth.com/daevalog.repo
sudo zypper install daevalog-dps-meter

Other systems

Steam Deck: through distrobox, as the Linux guide describes. Other distributions can build from source. Flatpak and AppImage are not supported: neither can give the capture helper the permission it needs.

Files: arch/x86_64/ pacman repository daevalog; deb/ apt repository (used by daevalog.sources); rpm/x86_64/ rpm repository for dnf, rpm-ostree and zypper (used by daevalog.repo).
